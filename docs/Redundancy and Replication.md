# Redundancy and Replication

## Redundancy
Redundancy is keeping **duplicate** nodes (servers or components), so that if one fails, another can take over.
The copies are not necessarily kept in sync.

## Replication
Replication is **duplication + syncing**: the nodes are copied, and their data is continuously kept in sync, so every copy has the same data.

## Key Difference
- **Redundancy** = duplicate copies (backup).
- **Replication** = duplicate copies that stay in sync.
